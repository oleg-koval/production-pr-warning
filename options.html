PR Redline

Warns you when a GitHub pull request targets a branch you care about.

Branches by colour Each colour has its own branches, one per line. * matches anything, e.g. release/*. If a branch is in two colours, the upper one wins. Wildcard patterns tint the page but are left out of the PR list block and the PR list highlight, because GitHub search has no wildcard for base branches. Light and dark follow your GitHub theme; the bar is the 4px stripe on top.
