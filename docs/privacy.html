PR Redline

Privacy policy

Last updated 27 October 2026

Short version

PR Redline collects no data. Nothing you do with it leaves your browser, and the developer receives nothing.

What the extension reads

  • It runs only on https://github.com/*.
  • On a pull request or compare page it reads the base branch name from the page to decide whether to tint it.
  • To list other open pull requests into protected branches, it loads the repository's own pull request list page from github.com, using the session you are already signed in with. No token is asked for or stored.
  • The Copy prompt button in that list writes a text prompt to your clipboard when you click it. It never reads the clipboard.

What the extension stores

Your settings (protected branch names, colours, and which features are on) are saved with chrome.storage.sync. Chrome keeps them in your browser profile and, if you have Chrome sync on, syncs them to your other devices through your Google account. The developer cannot see them.

What the extension sends

Nothing to the developer or any third party. It makes no network requests except the github.com page loads described above. It has no analytics, no tracking, no ads and no remote code.

Contact

Questions or issues: open an issue on GitHub.
