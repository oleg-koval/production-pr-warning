Tinted pull requests

Pages of PRs into main, production or your own patterns turn pale red with a bar on top. Merged ones fade.

Everything else in flight

The PR sidebar lists the other open pull requests into protected branches, and the PR list marks them with a badge.

Yours to tune

The toolbar popup shows what the current PR merges into, lets you edit branches, and picks colours from a wheel.

Install

  1. Download the extension and unzip it.
  2. Open chrome://extensions (or comet://extensions in Comet) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.

The Chrome Web Store listing is in review. Once it is approved, installing will be one click and updates will be automatic.

Runs only on github.com, uses your logged-in session, needs no token, and keeps its settings in your browser.

Also for GitHub pull requests: MergeChain blocks a PR's merge until the PRs it depends on land.
