Tinted pull requests

PRs into main or production turn pale red with a bar on top. Give staging green, release/* blue, or any colour you like. Merged ones fade.

Everything else in flight

The PR sidebar lists the other open pull requests into branches of the same colour, and the PR list marks each one in its colour. One click copies a Claude Code, Codex or OpenCode command that brings them all up to date.

Yours to tune

The toolbar popup shows what the current PR merges into, lets you edit each colour's branches, and adds new colours in one click.

How it works

Install

  1. Open PR Redline in the Chrome Web Store.
  2. Click Add to Chrome. It works in Comet, Edge, Brave and other Chromium browsers too.
  3. Open any pull request into main or production on github.com.

Updates install automatically. Prefer to load it by hand? Download the .zip, unzip it, and use Load unpacked on chrome://extensions with Developer mode on.

Runs only on github.com, uses your logged-in session, needs no token, and keeps its settings in your browser.

Also for GitHub pull requests: MergeChain blocks a PR's merge until the PRs it depends on land.
